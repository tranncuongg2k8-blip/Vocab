- **Claude:** Project Manager & Tech Lead
- **Codex:** Backend Developer & QA Tester
- **Gemini Antigravity:** Frontend & Interactive UI Developer

## Cách bắt đầu
1. Điền yêu cầu dự án vào `SPEC.md`.
2. Yêu cầu Claude đọc `CLAUDE.md` và `SPEC.md` để lập kế hoạch vào `PLAN.md`.
3. Yêu cầu Codex và Gemini đọc `AGENTS.md` và `PLAN.md` để thực thi.
